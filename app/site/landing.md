# Clair Piano

**Clair Piano** turns the M-VAVE FM-1 into a physical-modal concert grand piano with 16 stiff-string partials per voice, soundboard and bridge resonance, damper pedal physics, 87 public-domain classical pieces, **Tap Pianist** mode, **Piano Chord** mode, and a 4-slot live song recorder.

![Clair Piano playing Clair de lune on the Grand Stage view](manual/img/scene_pianist.png "Clair Piano on the FM-1 screen")

This is version **{{VERSION}}**. Installing custom firmware is at your own risk; the Web MIDI installer can return your unit to M-VAVE's official firmware at any time.

- **[Try it in the browser](emu/)** — play the real firmware with sound and full screen animations right here (computer keyboard or Web MIDI).
- **[Install via Web MIDI](install/)** — one-click install from Chrome or Edge over USB.
- **[Read the Manual](manual/)** — every deck, knob, keyboard mode, Tap Pianist, Chord Mode, and recorder control.
- **[Download `{{PKG}}`](firmware/{{PKG}})** — signed release package (`python3 base/tools/fm1_install.py {{PKG}}`).
- **[Source on GitHub](https://github.com/tokumine/fm1-claire-piano)** — free software under `MPL-2.0`, built on `fm1-base` and `felucca-bsp` (from Felucca by Leo Kuroshita, Hügelton Instruments).
